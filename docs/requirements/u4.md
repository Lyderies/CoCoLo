Stable replay means retained origins and sealed historical answers, fixed denial
replay, and the existing current-input rejudgment of a stored successful answer
(decision 44). It does not bypass publication checks, cooldown or bootstrap rules.
Tests use small histories (three lifecycles per family against limit two)
and advance deterministic wall clocks across the unchanged policy windows; large-scale timing does not belong in this suite.
No new index, schema version, record shape or release code is proposed.
AP/AP5's existing indexes are reused.

The supplied base has no probe launch journal or cross-restart probe reaper.
`docs/requirements/rsf-s5.md` records decision 188: preserve journal-less P6,
including its existing assertions. U4 must consume 3.3's accepted evidence path
rather than invent a second journal or silently replace that policy.
