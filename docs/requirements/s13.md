## Scope and limits of what is measured

- B1 times every outermost call into the register (`take_hold`, `arm_hold`, `release_hold`, `wake_before`,
  `wake_settled`) made while a real lease-backed run is reserved, armed, bound, published and its reservation obligation
  released through `project_release_ack._release_obligation`. Register writes share the existing transactions, so they add
  no commit of their own. The account receipt verification before that release is not part of the register's work.
  The memory-hold writer transactions (`measure_b7b.memory_writer_samples`) are added.
- B6 uses the product's start pass `release_earlier_unarmed_leases(limit=64)`. Blocked rows are live leases the pass skips
  without counting them against the batch, and it keeps no back-off, so every batch looks at all of them again. This is the
  only start pass that exists; the unattended orchestration close (batch of 4, back-off 10 s to 5 min) is the C6 row and is
  covered by `tests.test_b6_unattended_close`, not by this budget.
- `tests.test_b7b_budgets` still labels B1 and B6 `unmeasured` for its own narrower scope; this unit supersedes that label
  and leaves that test untouched.
