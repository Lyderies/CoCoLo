## S13E-2 — No unverified bytecode

Keep `PYTHON_ISOLATION_FLAGS` unchanged, including `-B -X pycache_prefix=/dev/null`.
No product bytecode cache is introduced. A planted timestamp-valid, stale, hash-based or source-less
`.pyc` must never execute, for both startup modules and modules first imported on demand. Source remains
the sole runtime input. Acceptance plants executable canaries in a temporary runtime copy and exercises
the actual host entry and deferred imports with the product isolation flags; no canary runs or cache grows.

VERSION and the runtime digest catalogue stay unchanged.
