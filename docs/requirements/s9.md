account state path, and Claude's own settings, but no general COCOLO user-settings
loader at this base. Installed policy files are integrity protected. S9 therefore
uses the existing account-state location for an optional `health-limits.json`,
with the two defaults in code. This avoids invalidating the installed runtime
when a user changes a warning. The primary should align this with any settings
work outside this base; the user was asked whether another established path exists.

metadata. No existing assertions are removed or changed. VERSION and the digest
