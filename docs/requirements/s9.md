## Fix round (040-s9-r1)

Use only Python's existing `sqlite3` library. A dedicated read-only copy connection
owns a pinned transaction from first page through backup completion; its worker
owns that connection exclusively. It never touches the mutable ledger owner's
connection. Backup progress pauses across passes; owner waits share the existing
500 ms deadline (150 ms copy allowance with queued work), below 750 ms. A 300 MiB
WAL store under an independent steady writer must complete copy and checks within
80 busy passes. The quick VM runs on the completed copy and resumes across visits,
then the full VM does likewise. No live quick-check restart/pending loop remains.
Copy-worker shutdown, scan joins and deletion run outside the ledger owner.

Growth needs at least six hours before comparing rates. Daily renewal retains the
older sample until the new window matures, comparing against that older sample
meanwhile; truncation and backwards clock correction reset without a short-window alarm.
User limits live in one account-state `user-settings.json`, loaded by a shared
validated typed module, visible before the first pass. Byte limits have a 1 MiB
minimum. Defaults follow owner decisions 340/341: 8 GiB size, 1 GiB/day growth,
2 GiB/5% disk headroom, 1.5 h no-merge warning. S10/S35 consume this same loader.

## Targeted follow-up (040-s9-r2c)

- S9-HM4-5: before any exclusive maintenance, the owner cancels its health copy
  and waits for the worker to release its read snapshot. Project deletion succeeds
  within the normal owner budget. Cancellation does not complete an integrity
  check; a later pass starts a fresh copy and completes it.
- S9-HM4-2: sustained growth remains reportable immediately after each daily
  renewal, using the previous baseline until the replacement has six hours of data.
- S9-HM4-1: classify copy failures by SQLite primary code (including extended
  codes). Only CORRUPT/NOTADB mean damaged data; FULL/IOERR report that the check
  could not run because of space or IO, and retry later without private error text.
