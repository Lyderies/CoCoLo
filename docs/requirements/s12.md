Q3 stays as built: lost-probe replay returns the kept answer, valid records commit after
workspace cleanup failure without the caller callback, and a never-launched admitted probe
still spends bootstrap admission and obeys cooldown. Existing M10/M5 and cooldown assertions
remain; `S12CollectorLoopTests.test_Q3_admitted_never_launched_probe_still_spends_bootstrap`
pins the bootstrap choice. The M9/M10 collector scenarios explicitly refuse the lost
caller callback while requiring record settlement and retained-answer replay. No schema or record format change.

All waits are bounded. New retry limits belong in `tests/lifetime_caps.json` with a test that
continues beyond the limit. No VERSION or runtime digest catalogue update belongs to S12.

Fix round (review `040-s12-r1`, fixed scope):
- M10 / H1c-1 (MED-1): only a probe root held as `not_reaped` may receive a
  `kill <pid>` hint. A `tree_not_confirmed` root is already reaped; status gives
  plain group/session checks without a pid-kill instruction.
- S12-N3 (LOW-1): raw SQLite BUSY/LOCKED failures, including an
  `OperationalError('database is locked')`, remain retryable past three record
  attempts, without falling back to denial. Other operational errors spend the budget.
- H1c-3 / H1c-1 (LOW-2): a missing signature process record permits only a
  bounded, non-signalling wait on its retained Popen handle. Inconclusive waits
  retain custody and name the missing process identity record in status; a successful
  wait still requires the existing descendant proof before restart can proceed.

The new `probe_records_unkept` name is an existing free-form lane-health cause, not a
durable refusal code, account operation, schema column or persisted record shape. No copier,
backup or move protocol changes.

Fresh probe rechecks reuse `ProcessTree.cleanup_after_owned_wait` and additionally
require an empty group and session. They cannot replace known live descendants or
irrecoverable tracking loss with marker absence. Containers keep their separate
container-gone proof, and active or unreturned workers are never rechecked.
